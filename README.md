Real-time streaming telemetry and predictive maintenance pipeline monitoring industrial machines (vibration, temperature, pressure, motor RPM) to identify early mechanical degradation and prevent unplanned assembly-line downtime.

---

## 📌 Architecture
- **Telemetry Ingestion**: High-frequency streaming sensors with rolling window aggregations (mean, standard deviation).
- **Early Degradation Detection**: Machine Learning classification flagging imminent equipment faults 45+ minutes prior to threshold breach.
- **Root Cause Isolation**: Feature importance highlighting harmonic vibration and thermal variance as primary precursors.
